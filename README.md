# Outlier adapter — 3D

Interactive 3D view of the Outlier threaded adapter: drag to rotate 360°, scroll or pinch to zoom.

- `index.html` — viewer (three.js)
- `outlier-adapter.glb` — model for web / Android AR / BigCommerce 3D apps
- `outlier-adapter.usdz` — model for iPhone / iPad AR
- `outlier-adapter-360.mp4` — turntable video

Model built from product photos; dimensions approximate.
